# Anamnez

[English](README.md)

Портативная диагностика Windows. Сбор журналов, подсчёт сбоев и локальный HTML-отчёт.

Anamnez собирает диагностические данные за один запуск и сохраняет исходные
файлы для дальнейшего разбора. Сбор и анализ работают локально, без интернета
и LLM.

## Системные требования

**Windows 7 SP1 → Windows 11, x64**, включая Windows 10. Python входит в
комплект. На Windows 7 нужны KB2533623 или заменяющее его обновление и
Universal C Runtime.

## Как запустить

1. Распакуйте ZIP и откройте `diagnostics.bat`.
2. Выберите `1` и подтвердите запрос прав администратора.
3. Откройте результат по пути в строке `RESULT:`. Если это архив `.7z`,
   распакуйте его и откройте `health.html` в браузере. Рядом будут TXT, JSON
   и исходные данные.

## Что собирает

- Журналы событий Windows, отчёты об ошибках WER и доступные дампы.
- Сведения об оборудовании, драйверах, дисках и SMART, автозагрузке, службах и сети.
- Журналы установки драйверов и обновлений, параметры питания и записи дампов.

В выгрузку входят журнал выполнения и контрольные суммы. По ним можно
проверить целостность файлов и увидеть, какие шаги сбора завершились с ошибкой.

## Что показывает отчёт

Скачайте [пример health.html](examples/health.html) и откройте его в браузере.
Пример построен на вымышленных данных.

В отчёте видны неожиданные перезапуски, BSOD, сбои приложений, ошибки записи
дампов, отдельные ошибки дисков и оборудования и общий SMART-статус, когда
его удалось прочитать. У каждой находки указаны приоритет, число эпизодов,
дата, время и источник каждого события. Если записи можно связать,
они собраны в один эпизод. Критические блоки открыты сразу, предупреждения
можно развернуть по мере разбора.

Подробный разбор дампов, оценка записей автозагрузки и поиск первопричины
требуют отдельной диагностики. Для неё в выгрузке остаются исходные файлы.
Отчёт отмечает недоступные источники и признаки сбитых часов.

Выгрузка может содержать имена пользователей и компьютеров, серийные номера
и сетевые сведения. Проверьте её перед передачей третьим лицам.

## Как подключить Autoruns

Anamnez собирает базовые сведения об автозагрузке средствами Windows.
Чтобы получить расширенный список, скачайте
[Autoruns с сайта Microsoft](https://learn.microsoft.com/en-us/sysinternals/downloads/autoruns),
распакуйте его и положите `autorunsc64.exe` в папку `anamnez\tools\autoruns\`
внутри распакованного комплекта Anamnez. Сборщик подхватит его при следующем
запуске.

[Инструкция по сборке ZIP из исходников](README.md#build-a-local-windows-package).
